Este projeto foi desenvolvido com a ajuda do Copilot (Microsoft) para a criação de um sistema de Bingo Online, que permite o cadastro de cartelas via upload de imagem ou captura pela webcam, reconhecimento automático dos números utilizando OCR (Tesseract.js), sorteio interativo com narração dos números, e gerenciamento de vencedores em tempo real através do Firebase Realtime Database.

O sistema inclui:

Login administrativo com controle de acesso.

Cadastro de cartelas com opção de câmera ou upload.

Reconhecimento de números das cartelas via OCR.

Sorteio automático com narração em voz.

Estatísticas de jogo em tempo real.

Registro e exclusão de vencedores (manual e automático).

O objetivo é oferecer uma experiência digital de bingo divertida, prática e acessível, integrando tecnologias modernas de reconhecimento de imagem, voz e banco de dados em nuvem.
